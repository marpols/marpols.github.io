	Climate and pest trend dashboard created with Microsoft Power BI for the Ontario Ministry of Agriculture, Food and Agribusiness extension blog ONVegetables (2020, updated in 2022). <a href="https://onvegetables.com/weather-dashboard/">Click here to view and interact with the dashboard on the blog</a>.

- 10 year averages are updated as new data is incorporated each year.
- Missing climate data is filled using <a href="https://power.larc.nasa.gov/">NASA POWER</a>.
- Pest thresholds are <a href="https://onfruit.ca/2022/08/12/benefits-of-monitoring-and-using-degree-days/">calculated using degree days</a> and indicate when pesticides should be applied for optimal impact against the specific pest. Green bars in the plots turn red to make visually assessing when the threshold has been reached very easy.
